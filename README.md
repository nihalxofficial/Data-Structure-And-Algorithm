## 📖 About

This repo started as C++ fundamentals practice and has since grown into an ongoing space for data structures & algorithms problem-solving. The goal isn't a one-time course follow-along — it's a continuously updated log of problems solved, patterns learned, and concepts revisited, built up over time as part of becoming a stronger, more disciplined programmer.

This is an evolving repo, not a fixed curriculum — new problems, topics, and patterns get added as they're practiced, so the sections below reflect what's here today rather than the full scope of the project.

## 🚀 Getting Started

Each folder/file is self-contained. Clone and explore:

```bash
git clone https://github.com/nihalxofficial/Data-Structure-And-Algorithm.git
cd Data-Structure-And-Algorithm
```

Compile and run any C++ file directly:

```bash
g++ filename.cpp -o output
./output
```
